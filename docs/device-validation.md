# 真机验收与现场诊断

本清单面向真实设备验证。策略断言证明决策，练习页证明可控场景，真实第三方应用证明实际节点与点击；三者分别记录。历史设备编号只用于追溯，每次操作先确认当前连接设备。

## 准备与证据

1. 使用 `adb devices -l` 确认设备、系统版本和用户当前前台；后续每条命令显式指定 `adb -s <serial>`。
2. 确认待装 APK 是 Debug 还是 Release、包名与签名；Debug 与旧应用并存，设置和授权独立。不擅自卸载旧应用或清数据。
3. 记录版本、设备/系统版本、场景步骤、预期与实际结果、证据时间；截图、日志和页面数据只存本地忽略目录，提交记录应脱敏。
4. 运行计时场景时优先截屏、只读 `dumpsys` 和可控交互。`uiautomator dump` 历史上曾干扰无障碍会话；读取节点前要记录该观察操作，并与会话计时验收分开。

每次验证在 `docs/validation/` 新建日期记录，列出 APK 校验和与实际设备。不要把所有格子默认标为通过。

## 必须覆盖的场景

| 场景 | 预期结果 |
|---|---|
| 首页与授权 | 大字可读、图标点击区域至少 48dp；OFF / CONNECTING / READY 准确；未选应用不能启动 |
| 应用选择 | 四个入口呈两行两列；未安装应用不能启动；更多应用可选，旋转保留选择 |
| 计时翻页 | 目标前台每次以 15–20 秒随机间隔翻页；后台、锁屏、手动暂停不发手势 |
| 广告倒计时 | 明确格式触发；重复同一数字不延期；普通推广、价格/点赞数/浮窗文字不触发 |
| 手动等待/结束等待 | 默认 15 秒；结束后不在同一画面马上重建等待；真实长倒计时不被截短 |
| 浮窗操作 | 拖动、收起、展开、暂停、继续、停止有效；展开收起不重置广告或弹窗等待 |
| 广告返回 | 只有预告后奖励完成才尝试返回；不同游戏名仍按信号处理；不点播放，不定时翻页 |
| 普通切换 | 切桌面/设置/最近任务不强拉回；广告返回的自主最近任务流程和用户切换可区分 |
| 返回找不到卡片 | 有限搜索后提示手动切回；不重启目标任务、不清理其他任务 |
| 模式切换 | 模式可见；旧等待与链路取消；切回计时模式从完整间隔开始 |
| 离开边界 | 2 分钟内回目标可继续；超过 2 分钟结束，回来不自启；手动暂停仍暂停 |
| 锁屏边界 | 立即暂停；超过 30 秒结束；唤醒先检查超时、不补发手势 |
| 可选总时长 | 默认不限时；用户开启后按所选时长停止，暂停和广告也计时 |
| 停止/服务重连 | 停止移除浮窗和轮询；解锁/回应用不自启；授权状态与连接状态分开 |

跨边界验收建议各观察边界前后，而不是只看任意中间时刻。锁屏与休眠还需覆盖回调迟到的情况。

## 淘宝弹窗专门验收

先在内置练习页分别覆盖打卡、提醒与已攒奖励三种状态，再在真实淘宝页面独立执行：

- 标题、内容和关闭按钮是否真实暴露节点，记录节点关系、描述与 resource-id；金额和提醒时间变化仍能匹配。
- 首次检测后暂停，10 秒内不翻页/不关闭；重复扫描与浮窗操作不延期。
- 10 秒后重新查找明确的右上角关闭控件；不点击打卡、领奖、提醒，不用照片坐标盲点。
- 提前消失取消点击，短暂节点丢失不误恢复；稳定消失约 0.5 秒后才恢复。
- 第一次失败至少间隔 2 秒再尝试，总计最多两次；无明确节点或失败时保持暂停并提示手动关闭。
- 切换应用、锁屏、暂停、停止取消计时，不能后台点击淘宝。

如果真实页面不暴露节点，记录“不支持该页面”或待分析，不将内置练习通过写为真实淘宝通过。

## 小米无障碍开关关闭的诊断

目前只有历史用户现象：系统中的开关与应用首页都显示关闭。原源码未发现主动撤权逻辑，但不能由此排除崩溃、系统策略或生命周期问题。自启动、省电限制等仅是假设。

尽量在问题发生后、重新授权前采集只读现场：

```powershell
.\scripts\collect-diagnostics.ps1 -Serial '<当前设备 serial>' -Package com.local.swipepilot.debug
```

诊断应关注系统授权列表、enabled/bound/crashed 服务、包 stopped 状态、退出/崩溃记录、系统日志、电池与后台限制。脚本采集不修改开关、不杀进程、不安装/卸载应用、不清用户数据。Android/OEM 可能限制某些命令，命令失败也应保留为证据。

脚本需要 PowerShell 7。`-Package` 只接受正式包名或 Debug 包名，`-Serial` 必填；可用 `-AndroidSdk` 指定 SDK、`-OutputDirectory` 指定本地证据目录。采集也包含 `SwipePilot` 的生命周期日志，其事件只含固定代码和异常类名。系统原始日志仍可能含私人信息，分享前须脱敏，不能提交到 Git。

记录“开关变 OFF”“仍授权但服务断连”“服务连接且会话已停止”中的实际类别，再形成可证伪的原因假设与复现步骤。不能通过偷偷写系统授权掩盖问题，普通应用也不能自行重新授予已关闭的无障碍权限。
